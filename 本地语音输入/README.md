# 本地语音输入 1.0.0

一个完全本地运行的 Windows 语音输入小应用。暖黄色小球常驻桌面，点一下说话，再点一下结束；识别、口语清理完成后才呈现文字。

## 日常使用

发布版在 `dist/本地语音输入`，双击 `本地语音输入.exe`。复制发布文件夹整体到其他 Windows 10/11 x64 电脑即可使用，不必安装 Python、注册账号或配置云端 API。请勿只拷贝 exe；它需要旁边的 `_internal`、`models`、`runtime` 文件夹。

- 点击小球、鼠标前进侧键 XButton2 或 Ctrl+Alt+Space：开始／结束录音。后退侧键 XButton1 不接管。
- 按住小球拖动更换位置。录音时显示声波，整理时转圈，不展示临时文字。
- 有原输入框时默认直接输入最终结果，不占用剪贴板；也可以右键关闭直接输入。
- 便签的双页按钮复制，叉号收起。右键可查看上次结果、识别原文、关闭口语整理或退出。
- 误触后没讲话：自动收起，不输出文字。上一条有效结果仍可通过右键查看。
- 位置和智能整理开关保存在 `%LOCALAPPDATA%/BubbleDictation`；听写内容仅在内存，不存盘。

## 功能与边界

中英文识别使用 sherpa-onnx 两遍模型；静音保护使用 Silero VAD；整理使用 CPU llama.cpp 和 Qwen3.5-0.8B Q4_0。完全断网可用，不占显卡。整理偏保守：明显误改、数字／英文／否定变化或超时会回退；不承诺全部口头词都删除，也不支持复杂改口或自动总结。超过 1800 字的听写跳过智能整理。

小球本身很小，但完整离线模型约 870 MiB；整套发布版大小以工具箱清单为准。语音和整理引擎总内存实测约 1.5–1.7 GiB，电脑配置和使用时长会影响实际占用。

极短、极弱语音可能被静音保护拦住；背景电视或其他真正的人声仍可能被识别。管理员程序输入需要以管理员身份运行本应用。

## 检查与维护

发布版：右键 `自检.ps1` 使用 PowerShell 运行，或调用 `本地语音输入.exe --self-test --report "报告路径.json"`。检查模型、静音保护与整理，不录音、不输入文字、不改剪贴板。
