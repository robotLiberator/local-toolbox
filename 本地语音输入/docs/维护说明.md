# 维护说明

## 结构

- `src/launcher.py`：独立入口、单实例和自检。
- `src/app.py`：录音、识别、拖动、全局热键、直接输入的共享控制逻辑。旧 Tkinter 界面已移除。
- `src/qt_ui.py`：小球、便签、逐像素透明与抗锯齿绘制。
- `src/speech_gate.py`：人声检测、前后静音裁剪、无讲话拒绝输出。
- `src/local_cleanup.py`、`text_cleanup.py`：模型口语整理、安全检查和规则去重。
- `src/paths.py`：应用资源与用户数据目录分离。
- `cleanup_prompt.txt`：可直接修改的口语清理要求，不用改模型或界面。
- `tests/`：不访问麦克风的回归测试。
- `product.spec`、`scripts/build.ps1`：可复现的发布构建流程。
- `models/`、`runtime/`：离线模型和原生引擎，不提交到 Git。

## 开发和构建

使用 Python 3.11 x64，在产品目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
$env:PYTHONPATH = "$PWD\src"
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe src\launcher.py
powershell -ExecutionPolicy Bypass -File scripts\build.ps1 -Python .\.venv\Scripts\python.exe
```

先放齐 `models` 和 `runtime/llama`（来源清单在 `cleanup_sources.json` 及第三方说明），再运行。Git 源码库不会包含这些大文件；完整发布备份则包含。

构建产物在 `dist/本地语音输入`。新增功能应先通过测试、独立 exe 自检，再更新工具箱 `清单.json`、`清单.md` 和版本号。不要将虚拟环境、打包缓存、用户便签、下载压缩包混入发布包。

## 个人部署

当前用户的桌面和开机启动快捷方式应指向工具箱发布版 exe。不在其他人的电脑上默认添加启动项或修改鼠标映射；复制文件夹本身不更改系统设置。

需要回退时退出小球，原工程位于 `E:/创世纪/本地产品备份/本地语音输入-封装前-20261001/原工程`；源码启动器可在该目录启动。原桌面／开机快捷方式也已备份，但其旧路径需要改成归档后的实际路径，不可直接复制回来就使用。

## Windows 打包注意

Qt 的 MSVC 运行库需优先使用其安装包自带版本。此环境的 PATH 中有 Poppler 的同名 ICU DLL，但 ABI 与 Windows 系统 ICU 不同；构建规格已明确排除错误捕获的 Poppler ICU。不能只做语音自检，还需确认 Qt 界面真正启动、侧键钩子就绪。
