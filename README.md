# 个人工具箱

已经封装的本地小应用、源码、检索清单和维护文档。该仓库是个人私有备份，不是公开商业发行。

## 本地语音输入

Windows 10/11 x64，暖黄色桌面小球，点击或鼠标前进侧键开始／结束录音。识别、口语整理、计算机／AI 术语纠错和静音保护全部本地运行，不占显卡，不展示临时转写，不自动覆盖剪贴板。

- [产品清单](清单.md) · [机器可读清单](清单.json)
- [使用说明](本地语音输入/README.md) · [维护说明](本地语音输入/docs/维护说明.md)
- [完整离线包](https://github.com/robotLiberator/local-toolbox/releases)：解压整个应用目录，再启动 `本地语音输入.exe`；不要只拷贝 exe。
- [默认术语词表](本地语音输入/terminology.json)：个人词表可通过小球右键菜单编辑。

Git 存源码、测试和构建脚本；大模型和引擎随 Release 离线包备份，不提交进 Git。仓库不包含听写历史、个人词表、位置配置或登录凭据。软件自身仅为本地文字整理启动回环接口，不将语音或文本送到 GitHub。

许可与模型来源见产品内第三方说明。公开或商业分发前需进一步完成第三方许可审核和代码签名。
