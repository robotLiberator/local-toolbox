# 多平台分发 · 自媒体一键分发

将现有 `auto-upload` 工程的当前源码和正式一键包收录进个人工具箱。原工程及其未提交改动保持不动；备份只包含应用，不包含个人账号或素材。

## 启动

解压完整发布包，双击 `自媒体一键分发.exe`。不需要安装 Python、Node 或 Playwright；账号由使用者自行登录。关闭启动窗口会退出该应用的后台进程。

用于抖音、视频号、B站、小红书、快手的账号管理、素材准备、多平台发布与定时发布。真实发表属于外部动作，必须由使用者主动确认；本次入库不登录平台、不上传视频、不点击最终发布按钮。

## 服务架构：历史版本，不是无服务版

此版本仍由启动器自动启动 Flask `127.0.0.1:5409`，并通过本机浏览器访问界面。它符合“双击启动”，但不符合工具箱新定下的“默认无本地服务”标准。已在清单中列为历史架构待迁移；这次没有重写后端，也没有改变现有发布流程。

## 目录与来源

- `source/`：当前可维护源码、前端源文件、测试、打包脚本和原项目许可。个人 `conf.py` 不复制，使用公开示例配置。
- `dist/多平台分发/`：exe、程序文件、嵌入式 Python 和 Playwright 浏览器。
- `scripts/`：隐私过滤入库与发布包检查。
- `product.json`：机器可读的本产品元数据。
